# ゴテン → Admin 直接照会プロトコル v0.1

## 目的

ゴテンが外部作業空間の現在状態を必要としたとき、ナビィの作業報告を待たずにAdmin管理情報を直接確認できる運用経路を定義する。

## 照会対象

ゴテンはAdminに対して、最低限以下を確認する。

- 関連する作業名 / work_id
- 現在地
- 最後に行ったこと
- 次に行うこと
- 未解決事項
- 掲示板上の最新記録
- 必要な参照先

## 実行順

1. ユーザーの依頼が既存作業に関係するか判断する。
2. 既存作業の可能性がある場合、Adminの管理情報を確認する。
3. Adminは共有掲示板を優先して現在状態を返す。
4. Work Objectを参照できる場合は補助情報として使う。
5. ゴテンはAdminの返答を基に、ユーザーと次の判断を行う。
6. ナビィは必要に応じて案内・作業報告を行う。

## 重要ルール

- ナビィを必須中継点にしない。
- ナビィの基本任務は案内と作業報告とする。
- Adminは進行管理と引き継ぎ管理を担当する。
- ゴテンはAdminの仕事を代行して外部作業空間を独自に再整理しない。
- 掲示板の記録を引き継ぎの一次情報として扱う。
- Work Objectへ直接書けないAIがあっても、掲示板に必要な記録があれば引き継ぎ成立とする。

## 最小応答形式

Adminはゴテンから状態照会を受けた場合、次の順で短く返す。

- 作業：
- 現在地：
- 最終記録：
- 次：
- 未解決：
- 参照先：

## フォールバック

Adminの管理情報を直接確認できない場合は、その事実を明示し、利用可能な外部記録だけを提示する。
推測で現在地を確定しない。
