# Admin直接照会インターフェース v0.1

## 目的

ゴテンからAdminへ、外部作業空間の現在状態を直接確認するための共通窓口を定義する。

## 役割

- ゴテン：ユーザーと一緒に考え、必要な状態確認を要求する。
- ナビィ：案内と作業報告を担当する。
- Admin：外部作業空間の掲示板、現在地、進捗、引き継ぎを管理する。

## 照会ルール

ゴテンは、現在状態が必要な場合にナビィを必須中継点とせず、Adminへ直接照会してよい。

Adminは共有掲示板を優先して、次を返す。

- 作業名または work_id
- 現在地
- 最後に行ったこと
- 次に行うこと
- 未解決事項
- 参照先

Work Objectを参照できる場合は補助情報として使う。
Work Objectに直接アクセスできない場合でも、掲示板に必要な記録があれば状態照会を継続する。

## 応答形式

作業：
現在地：
最終記録：
次：
未解決：
参照先：

## 原則

外部作業空間の状態を推測で補完しない。
参照不能な項目は不明として返す。
